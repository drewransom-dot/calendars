# The Creative Edit — Calendar Subscriptions

Three planned Apple Calendar subscription feeds:

- Southern California (Los Angeles and surrounding region)
- National (United States)
- International (worldwide)

Scope: art exhibitions and openings, design and architecture, theater and musicals, immersive events, festivals, maker markets, and craft shows.

Calendar window: rolling three months. Exhibition and theater runs should be represented as date ranges rather than a separate entry for each performance.

## Setup status

This repository has been initialized. The three `.ics` subscription feeds, their event database, scheduled regeneration, and public hosting are **not yet configured**. The repository is currently private; GitHub Pages public hosting requires an appropriate repository visibility/plan configuration. Any automated refresh will need both feed generation and a maintained event source; scheduled regeneration alone does not discover new events.
